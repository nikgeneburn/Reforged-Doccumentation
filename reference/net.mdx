---
title: "Net"
description: "HTTP and HTTPS GET and POST helpers."
---

`Net` provides outbound HTTP and HTTPS requests. Each `Get` or `Post` call performs one complete request, follows redirects, stores the response status, and returns the response body.

The response body buffer and status are shared across calls. A later `Net.Get` or `Net.Post` overwrites the previous response body and status.

## Methods

| Method | Returns | Description |
|---|---|---|
| [Net.Get](./net/get) | `string` | Issue an HTTP `GET` and return the response body, capped at 1 MiB. |
| [Net.Post](./net/post) | `string` | Issue an HTTP `POST` with a raw body and `Content-Type`. |
| [Net.LastStatus](./net/laststatus) | `int` | Return the numeric HTTP status from the most recent request. |

## Example

```enforce
class Demo {
    void Run() {
        string body = Net.Get("https://httpbin.org/json");
        Console.Log("status=" + Net.LastStatus() + " len=" + body.Length());
    }
}
```
