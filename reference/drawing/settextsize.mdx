---
title: "Drawing.SetTextSize"
description: "Sets the glyph height of a persistent Text object."
---

`Drawing.SetTextSize` configures the rendered glyph height of a persistent Text object.

## Signature

```enforce
static proto native void SetTextSize(int handle, int size);
```

## Parameters

- `handle`: a handle returned by [Drawing.New](new) with kind `"Text"`.
- `size`: rendered glyph height in pixels.

## Behavior

Persistent Text objects share the atlas rendering path used by transient [Drawing.Text](text). Default is 14 if never set.

## Edge cases

- Clamped to >= 1.
- Has no effect when the handle is invalid or the object is not `Text`.

## Example

```enforce
int t = Drawing.New("Text");
Drawing.SetTextSize(t, 18);
```
