---
title: "Memory.WritePointer"
description: "Write a full 64-bit pointer to game memory."
---

Writes 8 bytes (a full 64-bit pointer) at `addr`. Temporarily updates page protection, writes the value, and restores the previous protection.

## Signature

```enforce
static proto native void WritePointer(pointer addr, pointer value);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `addr` | `pointer` | Target address. |
| `value` | `pointer` | Value to write. |

## Returns

`void`. Has no effect when the address is invalid or the operation faults.

## Example

```enforce
Memory.WritePointer(someField, newPtr);
```
