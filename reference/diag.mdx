---
title: "Diag"
description: "Backtraces, process state, thread state, memory usage, and last-error diagnostics."
---

`Diag` provides static diagnostic helpers for the current process and calling thread. The methods are fault tolerant and return documented defaults on failure.

String-returning methods are copied into script-owned strings at the call boundary. Avoid depending on the native backing buffer after another `Diag.*` call.

## Methods

| Method | Returns | Summary |
|---|---|---|
| [Diag.Backtrace](./diag/backtrace) | `string` | Newline-separated hex return addresses for the calling thread. |
| [Diag.BacktraceWithModules](./diag/backtracewithmodules) | `string` | Backtrace lines annotated with module names. |
| [Diag.ModuleForAddress](./diag/moduleforaddress) | `string` | Resolve an address to `<module>+0x<offset>`. |
| [Diag.ProcessId](./diag/processid) | `int` | OS process id. |
| [Diag.ThreadId](./diag/threadid) | `int` | OS thread id for the calling thread. |
| [Diag.GetTickCount](./diag/gettickcount) | `int` | Low 32 bits of milliseconds since system boot. |
| [Diag.MemoryUsageKB](./diag/memoryusagekb) | `int` | Process working-set size in KiB. |
| [Diag.GetLastError](./diag/getlasterror) | `int` | Thread-local Win32 last-error value. |

## Example

```enforce
class Demo {
    void Run() {
        Console.Log("pid=" + Diag.ProcessId() + " tid=" + Diag.ThreadId());
        Console.Log("uptime ms=" + Diag.GetTickCount());
        Console.Log(Diag.BacktraceWithModules(8));
    }
}
```
