---
title: "Input.IsMouse5Down"
description: "Check whether mouse button 5 (X2) is currently held."
---

Return `1` while mouse button 5 (X2, the "forward" side button) is held, otherwise `0`. Wrapper around `IsKeyDown` for the standard X2-button virtual-key code.

## Signature

```enforce
static proto native int IsMouse5Down();
```

## Returns

`1` while held, otherwise `0`.

## Behavior

Polled at call time. Ignores window focus.

## Edge cases

- Same focus-ignoring semantics as [Input.IsKeyDown](./iskeydown).

## Example

```enforce
if (Input.IsMouse5Down()) {
    Console.Log("X2 held");
}
```
