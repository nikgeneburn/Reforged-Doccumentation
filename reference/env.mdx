---
title: "Env"
description: "Per-process key/value store that survives across executes."
---

`Env` is a fixed-cap key/value store. State survives across execute commands and across recompiles of the user script — it is how you keep state between script invocations without a filesystem. Each key holds exactly one kind (Int, Bool, FloatBits, or String); cross-kind reads return `0`.

## Methods

| Method | Returns | Description |
| --- | --- | --- |
| [Env.GetInt](./env/getint) | `int` | Get an `int` value by key. Returns `0` if the key is absent or holds a different kind. |
| [Env.SetInt](./env/setint) | `void` | Set an `int` value by key. Silent no-op when the pool is full. |
| [Env.GetBool](./env/getbool) | `int` | Get a `bool` value by key (as `0` / `1`). Returns `0` if the key is absent or holds a different kind. |
| [Env.SetBool](./env/setbool) | `void` | Set a `bool` value by key. Stores `v != 0` as `1`. |
| [Env.GetFloatBits](./env/getfloatbits) | `int` | Get a stored IEEE-754 bit pattern as `int`. Returns `0` if the key is absent or holds a different kind. |
| [Env.SetFloatBits](./env/setfloatbits) | `void` | Store an IEEE-754 bit pattern as `int`. |
| [Env.GetString](./env/getstring) | `string` | Get a string value by key. Returns `""` if the key is absent or holds a different kind. |
| [Env.SetString](./env/setstring) | `void` | Set a string value by key. Truncates to 255 chars; `null` becomes `""`. |
| [Env.Has](./env/has) | `int` | Returns `1` if any value is associated with the key, regardless of kind. |
| [Env.Erase](./env/erase) | `void` | Remove the entry for a key. No-op if absent. |
| [Env.Clear](./env/clear) | `void` | Zero-fill the entire pool. All prior `GetString` pointers become invalid. |
| [Env.AlreadyRan](./env/alreadyran) | `int` | Atomic check-and-set. Returns `1` if the key already held a non-zero `Int`; otherwise writes `Int=1` and returns `0`. |

## Putting it together

```enforce
class Demo {
    void Run() {
        if (Env.AlreadyRan("init")) {
            Env.SetInt("counter", Env.GetInt("counter") + 1);
            Console.Log("run #" + Env.GetInt("counter"));
        }
    }
}
```
