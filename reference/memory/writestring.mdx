---
title: "Memory.WriteString"
description: "Write a NUL-terminated string into game memory."
---

Writes `s` (including NUL) at `p`. Temporarily updates page protection, copies the value, and restores the previous protection. If the string or destination pointer is invalid, the call has no effect.

## Signature

```enforce
static proto native void WriteString(pointer p, string s);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `p` | `pointer` | Target address. |
| `s` | `string` | NUL-terminated source. If `s` is null, the call has no effect. |

## Returns

`void`.

## Example

```enforce
Memory.WriteString(playerNameSlot, "Player One");
```
