---
title: "Hooking.CallOriginal"
description: "Re-enter the original implementation and capture its return value."
---

Re-enters the original implementation of a hooked method and returns its captured return value. The path taken depends on whether the target was native-bodied or script-bodied.

## Signature

```enforce
static proto native int CallOriginal(int hookId);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| hookId | `int` | The slot id whose original implementation should be invoked. |

## Returns

The captured return value from the original implementation, or `0` on failure.

## Behavior

For native-bodied hooks, Reforged calls the saved engine handler with the captured argument state. For script-bodied hooks, Reforged temporarily restores the original method, executes it, reads the integer return value, and restores the hook. Use [IsHookNative](./ishooknative) to check which path is active.

## Edge cases

Calling `CallOriginal` from a callback that re-enters the same code path can produce undefined hook state. Avoid recursive call-through on the same hook.

## Example

```enforce
int ret = Hooking.CallOriginal(id);
```
