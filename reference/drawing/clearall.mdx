---
title: "Drawing.ClearAll"
description: "Wipes every persistent object slot in one pass."
---

`Drawing.ClearAll` resets the entire persistent object pool.

## Signature

```enforce
static proto native void ClearAll();
```

## Behavior

Invalidates every persistent object slot in one call. After this returns, no persistent object is visible, and every handle from before the call is invalid.

## Edge cases

- Intended for full resets, such as a level change or script restart, when every object should be removed without enumerating handles.
- After `ClearAll`, any cached handles in your script should be re-acquired via [Drawing.New](new) before reuse.

## Example

```enforce
Drawing.ClearAll();
```
