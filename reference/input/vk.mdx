---
title: "Input.VK"
description: "Look up a virtual-key code by name."
---

Look up the Win32 virtual-key code for a friendly name. Useful for keeping script code readable instead of hard-coding numeric VKs.

## Signature

```enforce
static proto native int VK(string name);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| name | string | VK name (case-insensitive). See below for accepted forms. |

## Returns

The virtual-key code, or `0` if `name` is empty or unrecognised.

## Behavior

The name is uppercased before comparison. Accepted forms:

- A–Z (also 0–9)
- `F1..F24`
- `NUMPAD0..NUMPAD9`
- Mouse: `LBUTTON`, `RBUTTON`, `MBUTTON`, `XBUTTON1`, `XBUTTON2`, plus `MOUSE1..5` as synonyms
- Modifiers: `SHIFT`, `CONTROL`/`CTRL`, `MENU`/`ALT`, with `L`/`R` variants (`LSHIFT`, `RSHIFT`, `LCONTROL`/`LCTRL`, `RCONTROL`/`RCTRL`, `LMENU`/`LALT`, `RMENU`/`RALT`)
- Locks: `CAPITAL`/`CAPSLOCK`, `NUMLOCK`, `SCROLL`/`SCROLLLOCK`, `PAUSE`, `PRINT`/`PRINTSCREEN`/`SNAPSHOT`
- Editing: `TAB`, `BACK`/`BACKSPACE`, `RETURN`/`ENTER`, `ESCAPE`/`ESC`, `SPACE`, `INSERT`/`INS`, `DELETE`/`DEL`, `HELP`, `CLEAR`
- Navigation: `PRIOR`/`PAGEUP`, `NEXT`/`PAGEDOWN`, `END`, `HOME`, `LEFT`, `UP`, `RIGHT`, `DOWN`, `SELECT`, `EXECUTE`
- Win: `LWIN`/`WIN`, `RWIN`, `APPS`, `SLEEP`
- Numpad operators: `MULTIPLY`/`NUMPADMULTIPLY`, `ADD`/`NUMPADADD`, `SEPARATOR`, `SUBTRACT`/`NUMPADSUBTRACT`, `DECIMAL`/`NUMPADDECIMAL`, `DIVIDE`/`NUMPADDIVIDE`
- OEM punctuation: `OEM_1`/`SEMICOLON`, `OEM_PLUS`/`PLUS`/`EQUALS`, `OEM_COMMA`/`COMMA`, `OEM_MINUS`/`MINUS`, `OEM_PERIOD`/`PERIOD`, `OEM_2`/`SLASH`, `OEM_3`/`TILDE`/`BACKQUOTE`, `OEM_4`/`LBRACKET`, `OEM_5`/`BACKSLASH`, `OEM_6`/`RBRACKET`, `OEM_7`/`QUOTE`/`APOSTROPHE`, `OEM_102`

## Edge cases

- Unknown name returns `0` silently — no log, no exception.
- Whitespace inside the name is not stripped; `VK("F 1")` does not match `F1`.

## Example

```enforce
int f1   = Input.VK("F1");
int shft = Input.VK("SHIFT");
int lmb  = Input.VK("LBUTTON");
```
