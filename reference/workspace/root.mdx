---
title: "Workspace.Root"
description: "Absolute path of the workspace root."
---

Returns the absolute path of the workspace root. The call creates `%APPDATA%\Lemons\Workspace` if it does not already exist. The trailing separator is stripped.

## Signature

```enforce
static proto native string Root();
```

## Returns

The absolute path of the workspace root as a string, or `""` if the directory chain cannot be resolved.

## Behavior

The returned string lives in a process-static buffer. Treat it as transient. Copy it into a script-owned string before calling another method that may reuse the same buffer.

## Example

```enforce
Console.Log("Workspace root: " + Workspace.Root());
```
