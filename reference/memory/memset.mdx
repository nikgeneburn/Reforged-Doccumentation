---
title: "Memory.MemSet"
description: "Fill a region with one byte value."
---

Fills `count` bytes at `dst` with `(byteVal & 0xFF)`.

## Signature

```enforce
static proto native void MemSet(pointer dst, int byteVal, int count);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `dst` | `pointer` | Destination address. |
| `byteVal` | `int` | Value to write. Only the low 8 bits are used. |
| `count` | `int` | Number of bytes to fill. |

## Returns

`void`. The call does nothing when `count <= 0`, `dst` is invalid, or the write faults.
