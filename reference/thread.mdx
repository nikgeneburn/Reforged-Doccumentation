---
title: "Thread"
description: "Spawn detached worker threads through the script runtime."
---

`Thread` starts OS worker threads that enter the script runtime through a class method or a file-scope function. Worker threads share the same native-call lock as the main script thread, so native calls run one at a time.

There is no script-side join. Coordinate completion and state through [Env](./env) or another script-visible mechanism.

## Methods

| Method | Returns | Summary |
|---|---|---|
| [Thread.Spawn](./thread/spawn) | `int` | Spawn a thread that instantiates a class and calls one method. |
| [Thread.SpawnGlobal](./thread/spawnglobal) | `int` | Spawn a thread that calls a file-scope global function. |
| [Thread.Sleep](./thread/sleep) | `void` | Sleep the calling thread for a number of milliseconds. |
| [Thread.GetId](./thread/getid) | `int` | Return the Win32 thread id of the calling thread. |

## Example

```enforce
class Worker { void Run() { Console.Log("hi from worker"); } }

class Demo {
    void Run() {
        int tid = Thread.Spawn("worker-1", "Worker", "Run");
        Console.Log("spawned thread id = " + tid);
    }
}
```
