---
title: "Hooking.SetHookEnabled"
description: "Enable or disable without freeing the slot."
---

Enables or disables a hook without freeing its slot. The descriptor swap is reversed in place, so a later re-enable re-attaches using the same id.

## Signature

```enforce
static proto native void SetHookEnabled(int hookId, int enabled);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| hookId | `int` | The slot id. |
| enabled | `int` | Non-zero to enable, `0` to disable. |

## Behavior

When enabled, the hook is restored for the selected slot. When disabled, the original implementation is restored so calls pass through normally.

## Example

```enforce
Hooking.SetHookEnabled(id, 0);   // freeze
```
