---
title: "Memory.Free"
description: "Release a region previously allocated by Memory.Alloc."
---

`VirtualFree(p, 0, MEM_RELEASE)`: releases the whole reservation. The `size` argument is accepted for API compatibility and ignored.

## Signature

```enforce
static proto native void Free(pointer p, int size);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `p` | `pointer` | Base from [`Alloc`](./alloc). |
| `size` | `int` | Accepted but ignored. |

## Returns

`void`. Has no effect when the pointer is invalid or the operation faults.

## Example

```enforce
Memory.Free(p, 0);
```
