---
title: "Console"
description: "Script logging through the host console, mirror log, and WebSocket clients."
---

`Console` provides the script logging channel. `Console.Log` writes one line to the host console, mirrors it to the debug log file, and broadcasts it to every connected WebSocket client.

## Methods

| Method | Returns | Description |
|---|---|---|
| [`Console.Log`](./console/log) | `void` | Print a script log line. |

## Conventions

- Every line is prefixed with `[Script] `.
- Log lines are mirrored to the debug log file.
- Connected WebSocket clients receive `{"type":"log","line":"..."}` messages.
- The maximum line length is 1024 bytes. Longer messages are truncated.
- Empty strings are valid and produce the `[Script] ` prefix with no message text.

## Example

```enforce
class Demo {
    void Run() {
        Console.Log("boot OK");
    }
}
```
