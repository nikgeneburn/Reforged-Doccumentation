---
title: "Memory.WriteHex"
description: "Write hex-formatted bytes into game memory."
---

Parses `hex` and writes the resulting bytes at `p`. Temporarily updates page protection, writes the value, and restores the previous protection. Max 1024 output bytes per call.

## Signature

```enforce
static proto native void WriteHex(pointer p, string hex);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `p` | `pointer` | Target address. |
| `hex` | `string` | `"48 8B C1"` or `"488BC1"` style. **No wildcards**: that is `AobScan`. |

## Returns

`void`. The call has no effect when the address is invalid or the operation faults.

## Edge cases

- Max **1024 output bytes** per call.
- Wildcards (`?`) are not accepted.

## Example

```enforce
Memory.WriteHex(funcAddr, "48 31 C0 C3");  // xor rax,rax; ret
```
