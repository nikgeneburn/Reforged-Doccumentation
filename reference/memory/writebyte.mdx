---
title: "Memory.WriteByte"
description: "Write a single byte to game memory."
---

Writes the low 8 bits of `value` at `addr`. Temporarily updates page protection, writes the value, and restores the previous protection.

## Signature

```enforce
static proto native void WriteByte(pointer addr, int value);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `addr` | `pointer` | Target address. |
| `value` | `int` | Value to write; only the low 8 bits matter. |

## Returns

`void`. Has no effect when the address is invalid or the operation faults.

## Example

```enforce
Memory.WriteByte(funcAddr, 0xC3);  // single-byte RET
```
