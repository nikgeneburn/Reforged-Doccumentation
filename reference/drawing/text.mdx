---
title: "Drawing.Text"
description: "Draws a text label once on the next render (currently deferred)."
---

`Drawing.Text` is the transient text primitive — intended to push a string into the overlay for the next frame.

## Signature

```enforce
static proto native void Text(int x, int y, string text, int argb, int size);
```

## Parameters

- `x`, `y` — top-left in screen-space pixels.
- `text` — string to render.
- `argb` — color in `0xAARRGGBB` form.
- `size` — point size.

## Behavior

Transient: queued for the next frame only. Persistent `Text` objects (configured via [New](new) and [SetText](settext)) share the same rendering path.

## Edge cases

- **Currently a deferred path** — the geometry packer skips text until a font atlas is wired up. Neither this nor persistent `Text` objects will render until that lands.
- `size <= 0` defaults to 14.
- Coordinates are top-left screen pixels — see the [overview](..).

## Example

```enforce
Drawing.Text(50, 50, "Hello", 0xFFFFFFFF, 16);
```
