---
title: "Memory.WriteFloat"
description: "Write a 32-bit float to game memory."
---

Writes 4 bytes at `addr`. Temporarily updates page protection, writes the value, and restores the previous protection. If the address is invalid, the call has no effect.

## Signature

```enforce
static proto native void WriteFloat(pointer addr, float value);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `addr` | `pointer` | Target address. |
| `value` | `float` | Value to write. |

## Returns

`void`. Has no effect when the address is invalid or the operation faults.

## Example

```enforce
Memory.WriteFloat(playerAddr + 0x44, 0.0);  // zero velocity
```
