---
title: "Input.IsMouse3Down"
description: "Check whether the middle mouse button is currently held."
---

Return `1` while the middle mouse button (mouse button 3) is held, otherwise `0`. Wrapper around `IsKeyDown` for the standard middle-button virtual-key code.

## Signature

```enforce
static proto native int IsMouse3Down();
```

## Returns

`1` while held, otherwise `0`.

## Behavior

Polled at call time. Ignores window focus.

## Edge cases

- Same focus-ignoring semantics as [Input.IsKeyDown](./iskeydown).

## Example

```enforce
if (Input.IsMouse3Down()) {
    Console.Log("MMB held");
}
```
