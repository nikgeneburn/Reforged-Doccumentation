---
title: "Memory.WriteInt64"
description: "Write a 64-bit value from two 32-bit parts."
---

Combines `hi` and `lo` into a 64-bit value, then writes eight bytes at `p`.

The written value is `((uint64_t)(uint32_t)hi << 32) | (uint32_t)lo`. Both parts are treated as unsigned 32-bit bit patterns.

## Signature

```enforce
static proto native void WriteInt64(pointer p, int lo, int hi);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `p` | `pointer` | Target address. |
| `lo` | `int` | Low 32 bits. |
| `hi` | `int` | High 32 bits. |

## Returns

`void`. The call does nothing if `p` is invalid or the write faults.

## Edge cases

- `lo` and `hi` are interpreted as `uint32` bit patterns. Sign extension is not performed.
