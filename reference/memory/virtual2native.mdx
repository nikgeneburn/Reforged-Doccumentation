---
title: "Memory.Virtual2Native"
description: "Return the pointer unchanged."
---

Returns the supplied pointer unchanged. The engine has already unwrapped the script handle by the time the native call runs; this exists for explicit documentation at the call site.

## Signature

```enforce
static proto native pointer Virtual2Native(pointer obj);
```

## Returns

`pointer`: `obj` unchanged.

## Example

```enforce
pointer nativePtr = Memory.Virtual2Native(someHandle);
```
