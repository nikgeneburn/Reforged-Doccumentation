---
title: "Memory.MemCopy"
description: "Copy bytes between two memory regions."
---

Copies `count` bytes from `src` to `dst` after validating both ranges.

## Signature

```enforce
static proto native void MemCopy(pointer dst, pointer src, int count);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `dst` | `pointer` | Destination address. |
| `src` | `pointer` | Source address. |
| `count` | `int` | Number of bytes to copy. |

## Returns

`void`. The call does nothing when `count <= 0` or either range is invalid.

## Edge cases

- This is not `memmove`. Overlapping ranges can corrupt data. Use a temporary buffer if overlap is possible.
