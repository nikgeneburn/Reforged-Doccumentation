---
title: "Diag.Backtrace"
description: "Return the calling thread's backtrace as newline-separated hex addresses."
---

Return the calling thread's backtrace as a newline-separated list of hex return addresses.

## Signature

```enforce
static proto native string Backtrace(int depth);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| depth | int | Maximum number of frames to capture. `0` or negative defaults to 16. Values above 62 are clamped to 62. |

## Returns

A newline-separated string of hex addresses, e.g. `"0x7FF6A1B0C2D0\n0x7FF6A1B12F80\n..."`.

## Behavior

The first frame is the helper itself and is elided. The first several frames after that are usually engine-side (interpreter loop, native dispatcher) rather than script — use [Diag.ModuleForAddress](./moduleforaddress) to disambiguate.

## Edge cases

- `depth <= 0` defaults to 16.
- `depth > 62` is silently clamped to 62.
- Return shares the process-wide buffer with other `Diag.*` string returns.

## Example

```enforce
Console.Log(Diag.Backtrace(8));
// "0x7FF6A1B0C2D0\n0x7FF6A1B12F80\n..."
```
