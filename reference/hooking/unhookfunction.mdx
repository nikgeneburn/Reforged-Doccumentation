---
title: "Hooking.UnhookFunction"
description: "Reverse an install and free the slot."
---

Reverses the install performed by [HookFunction](./hookfunction) for the given slot and zeroes the slot so it can be reused. No-fail.

## Signature

```enforce
static proto native void UnhookFunction(int hookId);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| hookId | `int` | The slot id returned by `HookFunction`. |

## Behavior

After this call, the slot can be reused. Calling this method with an invalid or already-unhooked id has no effect.

## Example

```enforce
Hooking.UnhookFunction(id);
```
