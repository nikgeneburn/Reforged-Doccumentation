---
title: "Diag.BacktraceWithModules"
description: "Backtrace annotated with the module each frame lives in."
---

Like [Diag.Backtrace](./backtrace), but each line is annotated with the module containing that frame: either `"<moduleFilename>+0x<offset>"` when the address falls inside a loaded module, or `"0x<hex>"` when it doesn't.

## Signature

```enforce
static proto native string BacktraceWithModules(int depth);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| depth | int | Maximum frames to capture. `0` or negative defaults to 16. Values above 62 are clamped to 62. |

## Returns

A newline-separated string of `"<module>+0x<offset>"` or `"0x<hex>"` lines.

## Behavior

Each frame is resolved independently against the loaded modules of the current process. Failures render that frame as bare hex.

## Edge cases

- `depth > 62` is silently clamped to 62.
- Return shares the process-wide buffer with other `Diag.*` string returns.

## Example

```enforce
Console.Log(Diag.BacktraceWithModules(8));
// "reforger.exe+0x1234000\nBackend.dll+0x8a40\n..."
```
