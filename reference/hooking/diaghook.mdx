---
title: "Hooking.DiagHook"
description: "Mode-specific inspection or diagnostic on a slot."
---

Runs a diagnostic query for a hook slot. Use it to inspect install failures or saved hook state.

## Signature

```enforce
static proto native int DiagHook(int hookId, int mode);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| hookId | `int` | The slot id. |
| mode | `int` | Which diagnostic to run. See below. |

## Returns

Mode-specific: see the table. Negative values are diagnostic error codes.

## Behavior

Negative return values are diagnostic codes:

- `-2` slot inactive
- `-3` invalid function descriptor
- `-4..-8` invalid return-slot pointer
- `-99` unknown mode
- `-100` fault in handler

Common modes:

| mode | What it does |
|---|---|
| `0` | Prints and returns the descriptor's return-slot pointer |
| `1` | Dereferences the return-slot pointer and returns the int stored there |
| `2` | Reads the saved opcode byte and returns `1` if it is `0x0B`. |
| `3` | Clears the return slot to `0` |
| `4` | Writes `0x42` into the return slot ("call succeeded" sentinel for re-entry) |
| `5` | Dumps descriptor fields plus a match flag |
| `6` | Reads first 8 bytes at the handler pointer; returns the lower 7 bits of the first byte |

## Example

```enforce
int slot = Hooking.DiagHook(id, 1);
```
