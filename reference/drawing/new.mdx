---
title: "Drawing.New"
description: "Creates a persistent overlay object and returns its handle."
---

`Drawing.New` allocates a slot in the persistent object pool for one of the supported kinds.

## Signature

```enforce
static proto native int New(string kind);
```

## Parameters

- `kind`: object kind (case-insensitive): `"Line"`, `"Square"`, `"Box"`, `"Rect"`, `"FilledRect"`, `"Circle"`, `"Text"`, or `"Font"`. `"Box"` and `"Rect"` alias `"Square"`. `"FilledRect"` aliases `"Square"` with filling enabled by default.

## Returns

- A handle `>= 1` identifying the new object.
- `0` if the kind is unknown or the pool is full (cap is 1024).

## Behavior

The returned handle is opaque to scripts. Newly-created objects default to **hidden**: configure the object with the matching `Set*` calls, then call [SetVisible](setvisible). Once visible, the object remains visible until explicitly hidden, destroyed, or cleared.

`"Font"` reserves a font object kind, but the current public `Drawing` surface does not expose font configuration methods. Text uses the built-in atlas font.

## Edge cases

- The pool cap is 1024 entries across all kinds. Beyond that, calls return `0`.
- Freed slots can be reused. A reused slot receives a new handle generation, so setters using a stale handle have no effect.
- Unknown kinds return `0` without raising an error.

## Example

```enforce
int box = Drawing.New("Square");
Drawing.SetPosition(box, 100, 100);
Drawing.SetSize(box, 200, 80);
Drawing.SetColor(box, 0xCC2266AA);
Drawing.SetFilled(box, 1);
Drawing.SetVisible(box, 1);
```
