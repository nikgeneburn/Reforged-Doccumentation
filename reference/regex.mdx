title: "Regex"
description: "ECMAScript regular expression helpers."
---

`Regex` exposes ECMAScript pattern matching through five static methods. Patterns are compiled on each call. Store reused patterns in script state or `Env` when that makes the calling code clearer.

## Methods

| Method | Returns | Description |
|---|---|---|
| [Regex.Test](./regex/test) | `int` | Return `1` if the pattern matches anywhere in the input. |
| [Regex.Match](./regex/match) | `string` | Return the first matched span, or `""` if there is no match. |
| [Regex.Find](./regex/find) | `int` | Return the byte index of the first match at or after `startIdx`, or `-1`. |
| [Regex.Replace](./regex/replace) | `string` | Replace all matches and support `$1..$9` back-references. |
| [Regex.Escape](./regex/escape) | `string` | Escape ECMAScript metacharacters so the input can be matched literally. |

## Example

```enforce
class Demo {
    void Run() {
        if (Regex.Test("[0-9]+", "abc 42 def 7")) {
            int at = Regex.Find("[0-9]+", "abc 42 def 7", 0);
            Console.Log("digit at " + at);
        }
    }
}
```
