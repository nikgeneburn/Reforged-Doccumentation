---
title: "Drawing.SetFilled"
description: "Toggles whether a persistent object is drawn as a solid fill or as an outline."
---

`Drawing.SetFilled` switches a persistent object between solid fill and outline modes.

## Signature

```enforce
static proto native void SetFilled(int handle, int filled);
```

## Parameters

- `handle` — a handle returned by [Drawing.New](new).
- `filled` — non-zero fills the interior, `0` draws the outline only.

## Behavior

For `Square`/`Box` and `Circle`, this picks between a solid filled interior and an outline at [SetThickness](setthickness) pixels.

## Edge cases

- No-op on bad handles.
- The fill color comes from [SetColor](setcolor); the outline color is the same.

## Example

```enforce
int box = Drawing.New("Square");
Drawing.SetFilled(box, 1);
```
