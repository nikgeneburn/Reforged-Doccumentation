---
title: "Crypt"
description: "Hashes, HMAC, base64, random bytes, and AES helpers."
---

`Crypt` provides static helpers for common encoding and cryptographic operations. It includes one-way hashes, keyed HMACs, secure random bytes, base64 encoding and decoding, and AES encryption and decryption.

String-returning methods are copied into script-owned strings at the call boundary. Treat returned strings as normal script values, but avoid relying on the native backing buffer after another `Crypt.*` call.

## Methods

| Method | Returns | Summary |
|---|---|---|
| [Crypt.Hash](./crypt/hash) | `string` | One-way digest as lowercase hex. |
| [Crypt.Hmac](./crypt/hmac) | `string` | Keyed digest as lowercase hex. |
| [Crypt.RandomHex](./crypt/randomhex) | `string` | Random bytes encoded as lowercase hex. |
| [Crypt.RandomBase64](./crypt/randombase64) | `string` | Random bytes encoded as base64. |
| [Crypt.Base64Encode](./crypt/base64encode) | `string` | Standard base64 encoding for a string. |
| [Crypt.Base64Decode](./crypt/base64decode) | `string` | Standard base64 decoding to a string. |
| [Crypt.AesEncrypt](./crypt/aesencrypt) | `string` | AES encryption that returns hex ciphertext. |
| [Crypt.AesDecrypt](./crypt/aesdecrypt) | `string` | AES decryption from hex ciphertext to plaintext. |

## Example

```enforce
class Demo {
    void Run() {
        string h     = Crypt.Hash("hello world", "sha256");
        string token = Crypt.RandomBase64(32);
        string enc   = Crypt.Base64Encode("hello");
        string k     = Crypt.RandomHex(16);
        string v     = Crypt.RandomHex(16);
        string ct    = Crypt.AesEncrypt(k, v, "secret payload", true);
    }
}
```
