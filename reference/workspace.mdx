---
title: "Workspace"
description: "Sandboxed filesystem access under %APPDATA%\\Lemons\\Workspace."
---

`Workspace` gives scripts a private directory on disk. Paths are anchored under `%APPDATA%\Lemons\Workspace` and validated before any filesystem operation.

The sandbox rejects traversal and unsafe path forms, including `..`, `:`, leading `/` or `\`, UNC prefixes, control characters, and Windows-reserved characters such as `< > " | ? *`. Methods return `0` or `""` on failure.

## Methods

| Method | Returns | Description |
|---|---|---|
| [NewFolder](./workspace/newfolder) | `int` | Create a directory under a parent path. |
| [NewFile](./workspace/newfile) | `int` | Create or truncate a file and write contents. |
| [ReadFile](./workspace/readfile) | `string` | Read a file's full contents. |
| [WriteFile](./workspace/writefile) | `int` | Create or truncate a file and write contents. |
| [AppendFile](./workspace/appendfile) | `int` | Append to a file, creating it if missing. |
| [DeleteFile](./workspace/deletefile) | `int` | Delete a single file. |
| [DeleteFolder](./workspace/deletefolder) | `int` | Delete an empty folder. |
| [IsFile](./workspace/isfile) | `int` | Test whether a path is an existing file. |
| [IsFolder](./workspace/isfolder) | `int` | Test whether a path is an existing folder. |
| [ListFiles](./workspace/listfiles) | `string` | List folder entries, with `/` suffixes for folders. |
| [Root](./workspace/root) | `string` | Return the absolute path of the workspace root. |

## Example

```enforce
Workspace.NewFolder("logs", "session");
Workspace.NewFile("logs/session", "today.txt", "started");
string list = Workspace.ListFiles("logs/session");
```
