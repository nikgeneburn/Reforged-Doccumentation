`Memory` is the workhorse. It handles reads, writes, allocations, protection changes, hex paste, AOB scans, and the helper-pointer arithmetic that everything else rests on.

## Pointer ABI

Every `pointer` argument and return is the full 64-bit address. **Never** pass addresses through `int` — `pointer` lives as a full 8-byte qword; truncating to `int` and dereferencing the result points at random memory.

## Sign and overflow semantics

The signed `int delta` passed to `Offset` and `Chain` is sign-extended properly. The unsigned `int rva` passed to the `*RVA` family is **zero-extended to 32 bits** — negative offsets wrap. If you need signed offsets, compute `Memory.GameBase() + offset` instead.

## Putting it together

```enforce
class Demo {
    void Run() {
        pointer base = Memory.GameBase();
        int one = Memory.ReadInt(Memory.Offset(base, 0x1234));
        Memory.WriteInt(Memory.Offset(base, 0x1234), one + 1);
        Memory.Nop(Memory.Offset(base, 0x5678), 5);
    }
}
```
