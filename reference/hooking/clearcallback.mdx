---
title: "Hooking.ClearCallback"
description: "Zero the slot's script callback."
---

Clears the script callback for the slot. Later dispatches use the constant return value set by [SetHookReturnInt](./sethookreturnint).

## Signature

```enforce
static proto native void ClearCallback(int hookId);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| hookId | `int` | The slot id. |

## Example

```enforce
Hooking.ClearCallback(id);
```
