---
title: "Drawing.Text"
description: "Draws an atlas-rendered text label once on the next render."
---

`Drawing.Text` queues a text string for the next overlay frame.

## Signature

```enforce
static proto native void Text(int x, int y, string text, int argb, int size);
```

## Parameters

- `x`, `y`: top-left in screen-space pixels.
- `text`: string to render.
- `argb`: color in `0xAARRGGBB` form.
- `size`: rendered glyph height in pixels.

## Behavior

Transient: queued for the next frame only. Text is emitted as indexed glyph quads from the built-in atlas. Persistent `Text` objects configured with [New](new) and [SetText](settext) share the same rendering path.

## Edge cases

- Empty strings are dropped.
- Printable ASCII uses the built-in 5 by 7 glyph set. Unsupported characters fall back to `?`.
- `\n` starts a new line and `\r` is ignored.
- `size <= 0` defaults to 14.
- Coordinates use top-left screen pixels. See the [overview](../drawing).

## Example

```enforce
Drawing.Text(50, 50, "Hello", 0xFFFFFFFF, 16);
```
