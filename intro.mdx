Reforged exposes a fixed set of static API classes to every script. The runtime prelude includes these declarations during compilation, so scripts can call the API without extra imports or local redeclarations.

## Available API classes

| Class | Purpose |
|---|---|
| `Console` | Script logging through `Log(string)`. |
| `Memory` | Pointer reads and writes, AOB scans, allocations, and hex helpers. |
| `Env` | Per-process key and value storage that survives across execute commands. |
| `Drawing` | Overlay primitives and persistent drawing objects. |
| `Hooking` | Install and manage hooks on supported engine methods. |
| `Net` | HTTP and HTTPS requests. |
| `WebSocket` | WS and WSS client connections. |
| `Input` | Keyboard and mouse polling. |
| `Thread` | Worker thread creation. |
| `Workspace` | Sandboxed filesystem access. |
| `Crypt` | Hashes, HMAC, base64, random bytes, and AES helpers. |
| `Regex` | ECMAScript regular expressions. |
| `Diag` | Backtraces, process state, thread state, and memory usage diagnostics. |

## Calling conventions

All API methods are static. There is no implicit `this`, and pointer values should stay in the `pointer` type.

| Script type | Native representation | Notes |
|---|---|---|
| `int`, `bool` | 32-bit register | `bool` values are represented as `0` or `1`. |
| `float` | `xmm` register | Values are passed as 32-bit floating point numbers. |
| `string` | `const char*` | Returned strings are copied into script-owned strings at the call boundary. |
| `pointer` | Full 64-bit address | Do not cast pointers through `int`; doing so truncates the address. |

## Error handling

Native calls are fault tolerant. Invalid input or a native fault returns the documented safe default instead of stopping the host process.

| Operation type | Failure result |
|---|---|
| Reads | `0`, `""`, or `0.0f`, depending on return type. |
| Writes | No effect. |
| String-returning calls | `""`. |
| Container access | Empty result. |

`Regex` additionally catches pattern and string exceptions so invalid expressions return documented defaults.
