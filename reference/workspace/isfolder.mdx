---
title: "Workspace.IsFolder"
description: "Test whether a path is an existing folder."
---

Returns whether the path exists and is a directory.

## Signature

```enforce
static proto native int IsFolder(string path);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| path | `string` | Path to test, relative to the workspace root. |

## Returns

`1` if the path exists and is a folder, `0` otherwise: including missing paths, files, validation failures, and access errors.

## Example

```enforce
if (Workspace.IsFolder("logs/session")) {
    Console.Log("dir exists");
}
```
