---
title: "WebSocket"
description: "WS and WSS client connections with polling-based receive."
---

`WebSocket` provides client connections for `ws://` and `wss://` endpoints. Up to 8 connections can be open at once. Scripts send text frames directly and poll `Receive` for inbound messages.

Connection states are `0` for closed, `1` for connecting, `2` for open, and `3` for closing.

## Methods

| Method | Returns | Description |
|---|---|---|
| [WebSocket.Connect](./websocket/connect) | `int` | Open a connection and return a handle in `[1, 8]`, or `0` on failure. |
| [WebSocket.Send](./websocket/send) | `int` | Send a text frame on an open connection. |
| [WebSocket.Receive](./websocket/receive) | `string` | Return the next queued inbound text message, or `""` if the queue is empty. |
| [WebSocket.State](./websocket/state) | `int` | Return the state for a connection handle. |
| [WebSocket.Close](./websocket/close) | `void` | Send a close frame and tear down the connection. |

## Example

```enforce
class WsDemo {
    void Run() {
        int ws = WebSocket.Connect("wss://echo.websocket.events");
        while (WebSocket.State(ws) != 2) { /* wait for OPEN */ }
        WebSocket.Send(ws, "hello");
        while (WebSocket.Receive(ws) == "") { /* wait for a frame */ }
        WebSocket.Close(ws);
    }
}
```
