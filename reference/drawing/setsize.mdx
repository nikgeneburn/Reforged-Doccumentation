---
title: "Drawing.SetSize"
description: "Sets the width and height of a persistent rectangle."
---

`Drawing.SetSize` configures the dimensions of a `Square`, `Box`, `Rect`, or `FilledRect` object.

## Signature

```enforce
static proto native void SetSize(int handle, int w, int h);
```

## Parameters

- `handle`: a handle returned by [Drawing.New](new).
- `w`: width in pixels.
- `h`: height in pixels.

## Behavior

Width and height in screen-space pixels, measured from the anchor set by [SetPosition](setposition) (top-left for squares).

## Edge cases

- Has no effect when the handle is invalid.
- Has no effect when the object is not a `Square`, `Box`, `Rect`, or `FilledRect`.
- Nonpositive dimensions are retained but do not emit geometry while the object is visible.

## Example

```enforce
int box = Drawing.New("Square");
Drawing.SetPosition(box, 40, 40);
Drawing.SetSize(box, 200, 16);
```
