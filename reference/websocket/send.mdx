---
title: "WebSocket.Send"
description: "Send a text frame on an open WebSocket connection."
---

Sends `msg` on `handle` as a single text frame. Returns `1` on success, `0` on failure (invalid handle, connection not `OPEN`, `null` msg, send error).

## Signature

```enforce
static proto native int Send(int handle, string msg);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| handle | `int` | The connection handle from [WebSocket.Connect](./connect). |
| msg | `string` | The text payload to send. Payloads are capped at 1 MiB. |

## Returns

`1` if the send succeeded; `0` on invalid handle, non-`OPEN` state, `null` msg, or transport error.

## Behavior

Sends serialize against the pump thread's close path so a `Close` racing against `Send` does not corrupt a partially-sent frame. Each handle has its own slot; sending on a different handle does not block.

## Edge cases

- Send before the connection is `OPEN` (state `1` connecting, `3` closing, `0` closed) returns `0`.
- `handle == 0` or out-of-range returns `0`.
- `msg == null` returns `0`.
- Payloads larger than 1 MiB are truncated without an error.

## Example

```enforce
int ws = WebSocket.Connect("wss://echo.websocket.events");
while (WebSocket.State(ws) != 2) { /* wait for OPEN */ }
WebSocket.Send(ws, "hello");
```
