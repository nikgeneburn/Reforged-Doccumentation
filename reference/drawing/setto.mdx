---
title: "Drawing.SetTo"
description: "Sets the second anchor of a Line or the size of a Square or Box."
---

`Drawing.SetTo` has two related meanings depending on object kind.

## Signature

```enforce
static proto native void SetTo(int handle, int x, int y);
```

## Parameters

- `handle`: a handle returned by [Drawing.New](new).
- `x`, `y`: end point for `Line`; width/height for `Square` or `Box`.

## Behavior

- `Line`: sets the endpoint (paired with [SetPosition](setposition) for the start).
- `Square` or `Box`: acts as an alias for [SetSize](setsize) (width, height).

## Edge cases

- Has no effect when the handle is invalid.
- On object kinds without a second anchor, the call has no effect.

## Example

```enforce
int line = Drawing.New("Line");
Drawing.SetPosition(line, 0, 0);
Drawing.SetTo(line, 200, 100);
```
