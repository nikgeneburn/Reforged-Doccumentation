---
title: "Net.LastStatus"
description: "Get the numeric HTTP status of the most recent Net.Get or Net.Post call."
---

Returns the numeric HTTP status code of the most recent [Net.Get](./get) or [Net.Post](./post) call. `0` before any call, on transport failure, or on a fault.

## Signature

```enforce
static proto native int LastStatus();
```

## Returns

The integer HTTP status code (for example `200`, `404`, `503`) of the most recent `Net.Get` or `Net.Post`. Returns `0` if no request has run, or if the most recent request failed at the transport layer.

## Behavior

The status is held in a single static slot, overwritten by the next [Net.Get](./get) or [Net.Post](./post). Failures reset the body to `""` and status to `0`.

## Edge cases

- `0` is not a valid HTTP status: observing it means the most recent request did not produce an HTTP response (transport failure, timeout, TLS error, pre-first-call, fault).
- 1xx-5xx are all returned for the corresponding response. The body is returned for any HTTP status; status and body together are how you tell success from failure.

## Example

```enforce
string body = Net.Get("https://httpbin.org/get");
if (Net.LastStatus() != 200) {
    Console.Log("request failed: " + Net.LastStatus());
}
```
