---
title: "Console.Log"
description: "Print a line with a [Script] prefix to the host console, the debug log file, and every connected WebSocket client."
---

`Console.Log` is the only method on `Console` exposed by the prelude. It writes to the host console, mirrors to the debug log file, and broadcasts `{"type":"log","line":"..."}` to connected WebSocket clients.

## Signature

```enforce
static proto native void Log(string msg);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `msg` | `string` | The line to print. Null or invalid pointer prints `[Script] (null)`. |

## Returns

`void`.

## Behavior

- Prefixes the line with `[Script] `.
- Writes to the host console. Mirrors to the debug log file. Broadcasts to all WS clients.
- Serialized under the global critical section: concurrent native calls do not interleave.
- No back-pressure on slow WS consumers; a stalled consumer will block this writer.

## Edge cases

- `msg == ""` is allowed; you will see `[Script] ` with nothing after it.
- `msg == null` or invalid pointer → line prints as `[Script] (null)`.
- Maximum line length is **1024 bytes**. Longer strings are truncated.

## Example

```enforce
class Demo {
    void Run() {
        Console.Log("boot OK");
        Console.Log("players = " + Memory.ReadInt(Memory.GameBase() + 0x1234));
    }
}
```
