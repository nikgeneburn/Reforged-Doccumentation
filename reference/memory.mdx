`Memory` provides low-level helpers for reading, writing, scanning, allocating, and walking process memory. Use the `pointer` type for all addresses and keep address arithmetic explicit.

## Pointer ABI

Every `pointer` argument and return value is a full 64-bit address. Do not pass addresses through `int`; that truncates the address and can make later reads or writes target the wrong location.

## Sign and overflow semantics

`Offset` and `Chain` sign-extend their `int delta` arguments. The `*RVA` methods zero-extend their `int rva` arguments to 32 bits, so negative offsets wrap. For signed offsets, use `Memory.Offset(Memory.GameBase(), offset)`.

## Example

```enforce
class Demo {
    void Run() {
        pointer base = Memory.GameBase();
        int value = Memory.ReadInt(Memory.Offset(base, 0x1234));
        Memory.WriteInt(Memory.Offset(base, 0x1234), value + 1);
        Memory.Nop(Memory.Offset(base, 0x5678), 5);
    }
}
```
