---
title: "Hooking"
description: "Install and manage hooks on supported engine classes and methods."
---

`Hooking` lets scripts intercept supported engine method calls. A hook can register a script callback, force a constant integer return value, or call through to the original implementation.

Hooks use a global table with 32 slots. When all slots are in use, new installs return `-1`. A slot remains allocated until `UnhookFunction` is called. Disabling a hook does not free its slot.

## Methods

| Method | Returns | Description |
|---|---|---|
| [HookFunction](./hooking/hookfunction) | `int` | Install a hook and return its slot id, or `-1` on failure. |
| [UnhookFunction](./hooking/unhookfunction) | `void` | Remove a hook and free its slot. |
| [CallOriginal](./hooking/calloriginal) | `int` | Call the original implementation and return its integer result. |
| [SetHookReturnInt](./hooking/sethookreturnint) | `void` | Set the constant integer return value for a hook. |
| [SetHookEnabled](./hooking/sethookenabled) | `void` | Enable or disable a hook without freeing its slot. |
| [GetHookInstance](./hooking/gethookinstance) | `pointer` | Get the captured instance pointer from the most recent invocation. |
| [GetHookParam](./hooking/gethookparam) | `int` | Get the low 32 bits of a captured parameter. |
| [GetHookParamCount](./hooking/gethookparamcount) | `int` | Get the parameter count recorded when the hook was installed. |
| [IsHookNative](./hooking/ishooknative) | `int` | Return `1` for native-bodied targets and `0` for script-bodied targets. |
| [DiagHook](./hooking/diaghook) | `int` | Run a diagnostic query for a hook slot. |
| [SetCallbackByName](./hooking/setcallbackbyname) | `void` | Register a script method as the hook callback. |
| [ClearCallback](./hooking/clearcallback) | `void` | Clear the callback for a hook slot. |

## Example

```enforce
int id = Hooking.HookFunction("PlayerController", "ProcessInput");
Hooking.SetHookEnabled(id, 0);
Hooking.SetHookReturnInt(id, 0);
```
