title: "Drawing"
description: "Overlay primitives and persistent drawing objects."
---

`Drawing` is the overlay API. It supports transient primitives for one-frame output and persistent objects that keep a handle across frames.

## Conventions

- Coordinates use screen-space pixels. The origin is top-left, +X moves right, and +Y moves down.
- Colors use ARGB format: `0xAARRGGBB`.
- Persistent handles are opaque positive integers. `0` means no object.
- The persistent object pool holds up to 1024 objects.
- `Destroy(handle)` and `ClearAll()` invalidate handles. Reused slots receive a new generation, so stale handles remain invalid.
- A visible persistent object remains visible until `SetVisible(handle, 0)`, `Destroy(handle)`, or `ClearAll()`.
- Invalid handles and invalid pointers return safe defaults instead of stopping the host process.
- Wait for `Drawing.IsOverlayReady()` before drawing the first frame.

## Methods

### Transient primitives

| Method | Description |
|---|---|
| [Line](drawing/line) | Draw a line segment for one frame. |
| [Box](drawing/box) | Draw an outlined or filled rectangle for one frame. |
| [Rect](drawing/rect) | Draw an outlined rectangle for one frame. |
| [FilledRect](drawing/filledrect) | Draw a filled rectangle for one frame. |
| [Circle](drawing/circle) | Draw an outlined or filled circle for one frame. |
| [Text](drawing/text) | Draw an atlas-rendered text label for one frame. |
| [IsOverlayReady](drawing/isoverlayready) | Return `1` once the overlay is initialized. |

### Persistent objects

| Method | Description |
|---|---|
| [New](drawing/new) | Create a persistent object and return its handle. |
| [Destroy](drawing/destroy) | Invalidate a persistent object handle. |
| [ClearAll](drawing/clearall) | Invalidate every persistent object. |
| [SetVisible](drawing/setvisible) | Show or hide an object. |
| [SetPosition](drawing/setposition) | Set an object's anchor position. |
| [SetTo](drawing/setto) | Set a line endpoint or the size of a square or box. |
| [SetSize](drawing/setsize) | Set square or box dimensions. |
| [SetRadius](drawing/setradius) | Set circle radius. |
| [SetColor](drawing/setcolor) | Set stored ARGB color. |
| [SetThickness](drawing/setthickness) | Set outline thickness. |
| [SetNumSides](drawing/setnumsides) | Set circle tessellation count. |
| [SetFilled](drawing/setfilled) | Choose filled or outlined rendering. |
| [SetText](drawing/settext) | Set a text object's string. |
| [SetTextSize](drawing/settextsize) | Set a text object's point size. |
| [SetZIndex](drawing/setzindex) | Set the object's sort key. |
| [SetTransparency](drawing/settransparency) | Set the transparency override, where `255` is opaque. |

## Example

```enforce
class Overlay {
    int _bg;
    int _fg;

    void Init() {
        _bg = Drawing.New("Square");
        Drawing.SetPosition(_bg, 40, 40);
        Drawing.SetSize(_bg, 200, 16);
        Drawing.SetColor(_bg, 0xAA000000);
        Drawing.SetFilled(_bg, 1);
        Drawing.SetZIndex(_bg, 10);
        Drawing.SetVisible(_bg, 1);

        _fg = Drawing.New("Square");
        Drawing.SetPosition(_fg, 40, 40);
        Drawing.SetSize(_fg, 200, 16);
        Drawing.SetColor(_fg, 0xFFCC3333);
        Drawing.SetFilled(_fg, 1);
        Drawing.SetZIndex(_fg, 11);
        Drawing.SetVisible(_fg, 1);
    }

    void SetHealth(float pct) {
        int w = (int)(200.0 * pct);
        Drawing.SetSize(_fg, w, 16);
    }
}
```
