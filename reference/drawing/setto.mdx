---
title: "Drawing.SetTo"
description: "Sets the second anchor of a Line or the size of a Square/Bobx."
---

`Drawing.SetTo` has two related meanings depending on object kind.

## Signature

```enforce
static proto native void SetTo(int handle, int x, int y);
```

## Parameters

- `handle` — a handle returned by [Drawing.New](new).
- `x`, `y` — end point for `Line`; width/height for `Square` / `Box`.

## Behavior

- `Line` — sets the end point (paired with [SetPosition](setposition) for the start).
- `Square` / `Box` — alias for [SetSize](setsize) (width, height).

## Edge cases

- No-op on bad handles.
- On kinds that don't have a "second anchor" the call is a safe no-op.

## Example

```enforce
int line = Drawing.New("Line");
Drawing.SetPosition(line, 0, 0);
Drawing.SetTo(line, 200, 100);
```
