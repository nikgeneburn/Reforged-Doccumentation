---
title: "Memory.Nop"
description: "Write 0x90 (x86 NOP) over a region."
---

Writes `0x90` for `count` bytes at `addr`. Temporarily updates page protection, writes the value, and restores the previous protection.

## Signature

```enforce
static proto native void Nop(pointer addr, int count);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `addr` | `pointer` | Target address. |
| `count` | `int` | Number of NOP bytes to write. **Hard-capped at 256**; over-cap is clamp without an errored. |

## Returns

`void`. The call has no effect when the address is invalid or the operation faults.

## Edge cases

- `count > 256` is clamp without an errored to 256. Choose a smaller patch size.

## Example

```enforce
Memory.Nop(funcAddr, 5);  // 5-byte NOP slide
```
