---
title: "Drawing.Line"
description: "Draws a line segment once on the next render."
---

`Drawing.Line` queues one transient line segment for the next overlay frame. It does not create a persistent handle or retain state after that frame.

## Signature

```enforce
static proto native void Line(int x1, int y1, int x2, int y2, int argb, int thickness);
```

## Parameters

- `x1`, `y1`: start point in screen-space pixels (top-left origin).
- `x2`, `y2`: end point in screen-space pixels.
- `argb`: color in `0xAARRGGBB` form.
- `thickness`: outline width in pixels.

## Behavior

The segment is queued for the next frame only. The call does not return a handle or retain state. It uses the same coordinate and color conventions as the rest of `Drawing`. See the [overview](../drawing).

## Edge cases

- `thickness <= 0` is clamped to 1.
- Coordinates are top-left screen pixels, not world space.
- If the overlay is not ready, the call is dropped without an error. Gate drawing on [Drawing.IsOverlayReady](isoverlayready).

## Example

```enforce
Drawing.Line(10, 10, 800, 600, 0xFFFF8800, 2);
```
