---
title: "Workspace.WriteFile"
description: "Create or truncate a file and write contents."
---

Creates or truncates the file at `path` and writes `contents` to it. The path may include a file name that does not yet exist.

## Signature

```enforce
static proto native int WriteFile(string path, string contents);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| path | `string` | Path to the file, relative to the workspace root. |
| contents | `string` | Data to write. |

## Returns

`1` on a full write, `0` on validation failure or write failure.

## Behavior

`path` is a full relative path: including the file name. Unlike [NewFile](./newfile), this does not split the parent path from the name. The file is opened, written, and closed in a single operation.

## Example

```enforce
Workspace.WriteFile("logs/session/today.txt", "started");
```
