---
title: "Drawing.IsOverlayReady"
description: "Returns 1 once the overlay is initialized and ready to draw."
---

`Drawing.IsOverlayReady` is the gate every script should poll before issuing the first frame of overlay output.

## Signature

```enforce
static proto native int IsOverlayReady();
```

## Returns

- `1` once the overlay is initialized and ready to accept draws.
- `0` otherwise.

## Behavior

This is a lightweight readiness check. During early startup, overlay initialization may still be in progress. Draw calls made before readiness are dropped without an error.

## Edge cases

- **Overlay startup:** until this returns `1`, transient draws and persistent-object updates are dropped without an error.

## Example

```enforce
while (!Drawing.IsOverlayReady()) { /* wait */ }
Drawing.Line(10, 10, 800, 600, 0xFFFF8800, 2);
```
