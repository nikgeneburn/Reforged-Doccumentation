---
title: "Env"
description: "Per-process key and value storage that survives across execute commands."
---

`Env` is a fixed-capacity key and value store. It persists across execute commands and script recompiles, which makes it useful for state that should survive between script invocations without using the filesystem.

Each key stores exactly one value kind: `Int`, `Bool`, `FloatBits`, or `String`. Reading a key as the wrong kind returns that method's default value.

## Methods

| Method | Returns | Description |
|---|---|---|
| [Env.GetInt](./env/getint) | `int` | Get an `int` value by key. |
| [Env.SetInt](./env/setint) | `void` | Set an `int` value by key. |
| [Env.GetBool](./env/getbool) | `int` | Get a `bool` value by key as `0` or `1`. |
| [Env.SetBool](./env/setbool) | `void` | Store `v != 0` as `1`, otherwise `0`. |
| [Env.GetFloatBits](./env/getfloatbits) | `int` | Get a stored IEEE-754 bit pattern as an `int`. |
| [Env.SetFloatBits](./env/setfloatbits) | `void` | Store an IEEE-754 bit pattern as an `int`. |
| [Env.GetString](./env/getstring) | `string` | Get a string value by key. |
| [Env.SetString](./env/setstring) | `void` | Set a string value by key. |
| [Env.Has](./env/has) | `int` | Return `1` if any value exists for the key. |
| [Env.Erase](./env/erase) | `void` | Remove the entry for a key. |
| [Env.Clear](./env/clear) | `void` | Clear the entire store. |
| [Env.AlreadyRan](./env/alreadyran) | `int` | Atomically check and set a one-time gate. |

## Example

```enforce
class Demo {
    void Run() {
        if (Env.AlreadyRan("init")) {
            Env.SetInt("counter", Env.GetInt("counter") + 1);
            Console.Log("run #" + Env.GetInt("counter"));
        }
    }
}
```
