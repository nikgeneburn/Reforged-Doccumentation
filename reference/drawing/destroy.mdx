---
title: "Drawing.Destroy"
description: "Invalidates a persistent object handle."
---

`Drawing.Destroy` frees a single slot in the persistent object pool.

## Signature

```enforce
static proto native void Destroy(int handle);
```

## Parameters

- `handle`: a handle returned by [Drawing.New](new).

## Behavior

Invalidates the handle and frees its slot for reuse. Later setter calls using the destroyed handle have no effect, even if a new object occupies the same slot.

## Edge cases

- Has no effect for `0`, unknown handles, or already-destroyed handles.
- A later object can reuse the slot with a different handle generation.
- Other script-side references to the destroyed handle do not stop the host process.

## Example

```enforce
int box = Drawing.New("Square");
Drawing.SetVisible(box, 1);
Drawing.Destroy(box);
```
