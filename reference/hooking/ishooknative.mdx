---
title: "Hooking.IsHookNative"
description: "1 if the target is native-bodied, 0 if script-bodied."
---

Reports whether the hooked target is native-bodied or script-bodied.

## Signature

```enforce
static proto native int IsHookNative(int hookId);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| hookId | `int` | The slot id. |

## Returns

`1` if the target is native-bodied, `0` if script-bodied. Also `0` if the slot is invalid or inactive.

## Behavior

Use this to decide which `CallOriginal` path will be used for the hook.

## Example

```enforce
if (Hooking.IsHookNative(id)) {
    Console.Log("native path");
}
```
