---
title: "Hooking.SetHookReturnInt"
description: "Set the constant integer return value for a hook."
---

Updates the constant integer return value used by the hook. If the hook is currently enabled, the active hook state is updated with the new value.

## Signature

```enforce
static proto native void SetHookReturnInt(int hookId, int value);
```

## Parameters

| Name | Type | Description |
|---|---|---|
| hookId | `int` | The slot id. |
| value | `int` | The new return value. |

## Example

```enforce
Hooking.SetHookReturnInt(id, 0);
```
