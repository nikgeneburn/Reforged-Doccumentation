---
title: "Thread"
description: "Spawn worker threads through the engine's thread wrapper. Single critical section governs native execution."
---

`Thread` spawns OS threads that re-enter the engine's interpreter at a class method or a global function. Threads run under the same global critical section as the script's main thread, so they're "fire-and-forget" — they queue on the lock, then run one at a time. There is no script-side join; coordinate work via [Env](./env).

## Methods

| Method | Returns | Summary |
|---|---|---|
| [Thread.Spawn](./thread/spawn) | int | Spawn a thread that instantiates a class and runs one of its methods |
| [Thread.SpawnGlobal](./thread/spawnglobal) | int | Spawn a thread that runs a file-scope global function |
| [Thread.Sleep](./thread/sleep) | void | Sleep the calling thread for N milliseconds |
| [Thread.GetId](./thread/getid) | int | Win32 thread id of the calling thread |

## Putting it together

```enforce
class Worker { void Run() { Console.Log("hi from worker"); } }

class Demo {
    void Run() {
        int tid = Thread.Spawn("worker-1", "Worker", "Run");
        Console.Log("spawned thread id = " + tid);
    }
}
```
